# scripts/agent-segmentation/secrets-allowlist-ops.txt  (profile: ops)
#
# Variable NAMES (never values) that HUMAN teammate accounts (group ctdc-ops)
# may read. secrets-subset.py --profile ops copies exactly these, verbatim,
# from /etc/corporatetraveldc/dispatch.env + dispatch-secrets.env into
# /etc/ctdc-ops/ops-secrets.env (root:ctdc-ops 0640). Everything not listed
# stays operator/container-only. See docs/AGENT_SEGMENTATION.md "Secrets".
#
# Derived 2026-10-04 from what a human OPERATING the stack (not developing
# the ingest) actually runs: the scripts/*.sh --status and watchdog modes,
# vault reads, the dispatch API through the web UI. Principle: a human gets a
# PERSONAL credential wherever the platform can issue one (auth_tokens rows
# for the API, a personal Nextcloud account/app password, a personal board
# token), and shared material only where no personal form exists.
#
# Format: one NAME per line; `#` comments; `?` suffix = optional.
